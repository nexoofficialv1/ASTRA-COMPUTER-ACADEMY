# Roadmap

## v0.1 Foundation - completed
Course library, lesson player, quiz, local progress, Typing Lab and Data Entry Lab.

## v0.2 Word Practical Core - completed
Word-like formatting/table practice with curriculum-driven assessment.

## v0.3 Excel Practical Core - completed
Spreadsheet grid, formula bar, cell addressing, arithmetic, SUM/AVERAGE/MIN/MAX/COUNT, range evaluation and task validation.

## v0.4 Office Practical Expansion - completed
Word office documents, Excel office sheets, richer typing/data-entry tasks and generalized Word/Excel practical routing.

## v0.5 Learner & Mastery System - completed
Student profile, sequential progression, mastery, streak, badges, final practical exam and offline certificate.

## v0.6 Windows, Internet & Data Portability - completed
Windows/File Manager, Internet Browser simulation, integrated office project, JSON Backup/Restore and certificate text/HTML export foundation.

## v0.7 Basic Computer Completion Part 1 - completed at source level
PowerPoint, advanced Excel functions, Word Save/Print workflow and Windows keyboard shortcuts.

## v0.8 Basic Computer Release Candidate Source - completed at source level
- 60 lessons / 40 interactive practicals
- Word Header/Footer/Page Number
- Excel Percentage / Sort / Filter / Chart / Print Setup
- Windows Desktop / Start / Taskbar / window control simulator
- Email compose / attachment and email safety
- 9-component Final Practical Exam
- printable offline PDF certificate export
- source-level consistency test suite

Mail Merge is deferred to a later Office-Advanced module; it is not required for this Basic Computer release candidate.

## v0.9 UI Implementation - completed at source level
- ASTRA navy/blue visual system
- Branded splash/dashboard
- Home / Courses / Practical / Progress / Profile navigation
- Course Lessons/Practicals tabs
- Approved UI reference retained in `docs/UI_REFERENCE_v0.9.png`

## v1.0 Android Build-Ready Hardening - completed at source level
- Build-time Android scaffold generation from the active Flutter SDK
- ASTRA Android launcher icon/native splash overlay
- Offline-oriented manifest hardening
- GitHub Actions analyze/test/APK pipeline
- Local release build script
- Small-phone dashboard layout adaptation
- Source/build-contract validation package

## First APK validation gate - next
- Run GitHub Actions with Flutter stable
- Fix any real compiler/linter/test failures
- Install generated APK on Android hardware
- Execute end-to-end learning and persistence smoke test
- Freeze a tested RC build before broader distribution

## Later
Advanced Word/Mail Merge, Tally/accounting, advanced office projects, coding track (HTML/CSS/JavaScript/Python etc.), cloud account/sync backend, Web app, Windows app and online certificate verification.
